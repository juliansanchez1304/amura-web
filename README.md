# Amura Movilidad Eléctrica — web estática

Web de amurashop.es migrada desde Shopify a HTML estático, alojada gratis en Cloudflare Pages.

- Páginas: `index.html`, `pages/`, `blogs/`, `policies/`
- Imágenes y estilos: `assets/`
- `sitemap.xml`, `robots.txt`, `_redirects`, `_headers`: configuración de Cloudflare Pages
- `tools/`: scripts usados en la migración y servidor local de prueba (`python3 tools/serve.py .`)
